# Dwelling Load Calc

Residential service load calculator for Vision Electrical. Runs the NEC 2026 Article 120 Optional method (120.82) and Standard method (Part III) for a one-family dwelling on a 120/240 V single-phase service, and exports a PDF worksheet.

Live page: https://leeatvision.github.io/load-calc/

To update the calculator, replace `index.html` and commit to `main`. GitHub Pages republishes within a few minutes.
